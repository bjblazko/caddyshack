CaddyShack

Analyzes Caddy access logs on the server they come from: how much traffic, from which countries, with which browsers, for which pages — down to the single request.

Your data

CaddyShack makes no requests to anyone else: no telemetry, no update check. Uploaded logs stay on this server and are deleted once unused for the configured time (one hour by default). IP addresses are shortened before they reach your browser.
